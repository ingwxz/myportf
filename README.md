# Portfólio — Ingridy Davantel

Projeto feito com HTML, CSS e JavaScript puro para facilitar a abertura e a edição no VS Code.

## Estrutura

```text
portfolio_ingridy/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── referencias-visuais.md
└── README.md
```

## Como abrir no VS Code

1. Extraia o arquivo ZIP para uma pasta do computador.
2. Abra o VS Code.
3. Vá em **Arquivo > Abrir Pasta** e escolha `portfolio_ingridy`.
4. Abra `index.html`.
5. Para visualizar, clique com o botão direito em `index.html` e escolha **Open with Live Server** (se a extensão Live Server estiver instalada). Também é possível abrir o arquivo diretamente no navegador.

## Antes de entregar

- Confirme se os três links dos projetos estão corretos.
- Confirme se o número do WhatsApp e o e-mail são os que você quer divulgar.
- A paleta e o layout são personalizados; as imagens dos projetos foram montadas em CSS como prévias ilustrativas, não são capturas reais dos sites.
- As fontes Nunito e DM Sans são carregadas do Google Fonts; sem internet, o site usa fontes alternativas.
- Teste a navegação no computador e no celular.

## Tecnologias

- HTML semântico
- CSS responsivo, grid e flexbox
- JavaScript para menu mobile e animações de entrada
